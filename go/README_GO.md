# PPTP Warrior Pro - GO Edition (v7.0)

## نظرة عامة
تم إعادة بناء مشروع PPTP Warrior Pro بالكامل باستخدام لغة **Go (Golang)** لتحقيق أقصى درجات الأداء والسرعة. يعتمد هذا الإصدار على الـ Goroutines للتعامل مع آلاف العمليات المتوازية بكفاءة عالية واستهلاك موارد منخفض جداً.

## الميزات الجديدة في إصدار Go
*   **سرعة هائلة**: أداء أسرع بعشر مرات من نسخة البايثون والباش بفضل التزامن الأصيل في Go.
*   **تطبيق واحد متكامل**: دمج محرك التخمين، محرك فحص الشبكة، ومحرك الـ ASN في ملف تنفيذي واحد.
*   **دعم عابر للمنصات**: يعمل على Linux و Windows بنفس الكفاءة.
*   **إدارة ذكية للنتائج**: تنظيم تلقائي للنتائج في مجلدات منفصلة لكل اتصال ناجح.
*   **تكامل SIPVicious**: فحص متخصص للمنفذ 5060 (SIP) لسحب معلومات أجهزة VoIP بدقة عالية.

## المتطلبات
*   **نظام Linux**: حزمة `pptp-linux` و `sudo`.
*   **أدوات الفحص**: `nmap` و `sipvicious` (يمكن تثبيتها عبر `pip3 install sipvicious`).
*   **نظام Windows**: تشغيل كمسؤول (Administrator).
*   **لغة Go**: (فقط إذا كنت تريد إعادة البناء من الكود المصدري).

## طريقة التشغيل
1.  قم ببناء المشروع:
    ```bash
    go build -o pptp_warrior cmd/pptp_warrior/main.go
    ```
2.  شغل البرنامج:
    ```bash
    sudo ./pptp_warrior -u config/users.txt -d config/Domains.txt -T 50
    ```

## الخيارات المدعومة
*   `-u`: مسار ملف المستخدمين.
*   `-d`: مسار ملف الأهداف.
*   `-T`: عدد الخيوط المتوازية (Threads).
*   `-t`: مهلة الاتصال بالثواني.
*   `-P`: المنافذ المراد فحصها (مثال: `80,443,5060`).
*   `-asn`: رقم الـ ASN للفحص التلقائي.
*   `-v`: وضع المراقبة المفصلة.
